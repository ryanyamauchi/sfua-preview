06 — Data

Sync, export, provenance

How it works

  1. Each partner signs in with the login SFUA provides — one per organization.
  2. Enter or edit your sites in the Intake tab. Changes save to the shared database and appear for every signed-in partner within seconds.
  3. SFUA uses the combined dataset for network modeling and optimization — matching local growers to local buyers without disturbing existing operations.

The network is private while we build it: viewing and editing both require a partner login. Need one? Email ryanyamauchi@sfua.org.

Your data

Data principles

  • Each organization owns its entries and shares only what it chooses to.
  • Existing contracts and the people currently served are recorded so coordination never disrupts them.
  • The shared dataset exists to optimize the whole network: matching local growers to local buyers, filling storage and transport gaps, and keeping the operation in the black.
